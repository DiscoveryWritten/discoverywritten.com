Autumn Valenta is a web & Python programmer, fiction author, and content creator on YouTube.

Her longform tutorial YouTube series aims to help creators learn to use the Ren'Py visual novel engine to build narrative games with unique elements using a dusting of Python.

Elsewhere on the web, she manages technical work at Mythulu, a publisher of software, short fiction, and advice articles.
