Button Crash

A creativity experiment I outlined for myself: the tracks would predominately feature the chip-tuney and piano sounds. There would be five tracks, named for the letters in “CRASH”. I would name the tracks before lifting a finger. I would try to do one track per day and then move to the next.

I decided to allow myself to refine the names as I went, but concept-wise they would stay the same.
